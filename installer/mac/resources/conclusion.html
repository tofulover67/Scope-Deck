Scope Deck is installed.

  1. Start DaVinci Resolve and add Scope Tap (OpenFX, Scope Deck group) to a node on the Color page.
  2. Open Scope Deck from Applications, or press the plugin's Open Scope Deck button.

The installer switches App Nap off for DaVinci Resolve, so playback keeps running when Scope Deck covers its window; it takes effect the next time Resolve starts. If playback still runs away with Resolve hidden, run this once in Terminal:
defaults write com.blackmagic-design.DaVinciResolve NSAppSleepDisabled -bool YES

The Timecode and Subtitle panels need Python 3.10 or newer and Resolve Studio's scripting. If no Python was found, the installer downloads one from python.org; a Mac that was offline just now can install one later.

The Audio Meter asks once for permission to capture system audio, and Screen Capture asks for Screen Recording; both are in System Settings > Privacy & Security.
