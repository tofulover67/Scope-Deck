This installs Scope Deck into Applications and the Scope Tap OpenFX plugin for DaVinci Resolve into /Library/OFX/Plugins.

If the Mac has no Python from python.org yet, one is downloaded and installed for the Timecode and Subtitle panels (standard library only; nothing else is added).

Quit DaVinci Resolve before continuing. Resolve scans OpenFX plugins only when it starts.
